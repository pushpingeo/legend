What this is

The Shell Standard Legend (SSL) is a century-old symbol standard for exploration maps, from Dr Erb's 1917 Uniformity in Geological Reports to the 2016 edition Shell released to industry through IOGP. It worked while drawing offices applied it by hand. Once data arrived faster than anyone could code it, it mostly stopped being used.

This page tests a different route. The legend is turned into data (codes, names and SVG symbols built from the SSL fonts), and Claude does the coding step: it reads a service's fields and values and writes a mapping from them to SSL codes, with a confidence and a reason for each. The map then draws from the mapping. Nothing about the source data changes.

Where a service doesn't hold something the SSL can show, the symbol says so. BOEM's well layer has status but no test results, so its wells show as plain circles while NSTA's show oil and gas.

Symbols: SSL2012 Esri style and fonts as released by Shell via IOGP, plus 2016 pipeline symbols and the suspended-well series built from the same glyphs. Data: NSTA and BOEM open data, fetched . Built by Rob Dunfey with Claude. Source.
